# Numby and the Glitch Galaxy

Adaptive elementary math adventure (K–5). One HTML file. No install, no account, no internet after you open it.

ZIP sneezed the universe. The kid is the Reality Mechanic who stitches it back together with math.

## Play

1. Open [`numby-glitch-galaxy.html`](./numby-glitch-galaxy.html) or [`index.html`](./index.html) in Chrome, Safari, or Edge (laptop, tablet, or phone).
2. Type the child's name. That name is how progress is saved on this device.
3. Pick **Quick pulse** (8 missions, ~5 min), **Standard orbit** (12, ~10 min), or **Deep scan** (18, ~18 min).
4. Play. Tap **I'm guessing** only when it is a hunch.
5. Read the kid debrief, then the grownup briefing.
6. Print the 20 practice missions + answer key.

Same name next time → ZIP welcomes them back and starts near the last orbit.

## What it measures

Six gauges: Number Power, Operation Moves, Fraction Quest, Shape & Measure Lab, Pattern Radar, Story Missions.

Placement is a snapshot, not a formal test. Lucky guesses are down-weighted when the child flags **I'm guessing**. Follow-up echo pings check whether a hit was real.

## Files

- `numby-glitch-galaxy.html` / `index.html` — the game
